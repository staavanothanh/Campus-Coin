## Current integration boundaries

- JEV route remains advisory only. It allows only exact, reviewed locale/type-specific seeded default category labels to reach the injected service; every custom category label, including one that duplicates a safe default label or contains sensitive text, is withheld before the call and returns `manual/privacy`. The backend worktree has no browser surface or app bootstrap that composes `ApiDependencies`; callers must explicitly inject the internal service, and absent injection returns `disabled/flag_off`. No provider call/config enablement occurs here.
- The route validates injected service results against the public response contract, but the backend has no host-level request-rate, concurrency, or spend controls; there is also no runtime service composition. These remain blockers before any provider-enabled deployment. Raw request description still crosses the generic injection seam under `descriptionRedacted`; the concrete category service redacts before provider adapter, but this seam is not safe to treat as provider-ready.
- The ledger's `confirmedCategorySuggestion` boolean is not bound to a suggestion response or an acceptance interaction. Do not describe it as evidence of user consent or use it as such.
- Luna/NghienAI remains transport plumbing only. No canonical approved feature/capability or contract exists. Do not use it as JEV replacement/fallback or connect it to any money path.
- The existing 60-row synthetic threshold set contains pre-authored IDs and confidences, not prompts, locale, provider results, schema outcomes, user corrections, latency or cost. The measured held-out 75% synthetic precision is a warning against treating this fixture as model evidence, not a model result or runtime threshold.
- DevD app/API topology review confirms no production host, server bootstrap, or `handleApiRequest` consumer in this worktree; handler calls are tests only. A pinned, read-only DevC snapshot exists elsewhere but has neither description/category picker/JEV UI nor working ledger/JEV route mounts. No front-end or provider integration is delivered here.
