## Shared interpretation contract

- `[Đã kiểm chứng]`: official TypeSafe/OpenRouter documentation or Campus Coin SRS/canonical fact; not runtime evidence.
- `[Đề xuất]`: product/architecture recommendation that needs owner approval; not a new API/domain decision.
- `[Chưa chốt]`: missing semantics/evidence; fail closed and do not invent.
- System One answers questions independently while sharing request state; questions are not a hidden agent loop. Code chooses sequencing, deterministic validation/calculation, action authorization and side effects.
- `Choice` fits finite alternatives; `Noul` fits explicit unknown/abstain only where official primitive semantics support it; `Score` fits numeric/ranking/threshold signals only with product semantics. No primitive produces explanation/prose or selects a next action.
- Every advisory result must carry provenance and user-facing explanation generated by application UI from typed fields/labels; JEV itself must not generate explanation text.
- Old `docs/working/jev-product-analysis/` artifacts are read-only baseline and MUST NOT be edited.

## Dependency/risk

- Lanes 001–004 are independent and have disjoint handoff files. Integrator 005 waits for all four handoffs.
- Main risk: treating typed decisions as natural-language reasoning; this would overstate monthly narrative, tips, coaching and NBA fit. Other risks: score-as-certainty, missing abstention, stale shared state, model output driving side effects, privacy/input injection and SRS scope creep.
- Provider/cost is explicitly out of scope; only user-verified prerequisite is acknowledged.
